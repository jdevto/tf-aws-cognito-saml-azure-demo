How It Works

This demo showcases AWS Cognito configured with Azure AD as an OIDC identity provider.

  1. Click "Login with Azure AD" - You'll be redirected directly to Azure AD (authentication happens there)
  2. Authenticate - Sign in with your Azure AD credentials at Microsoft
  3. Azure AD redirects back - To Cognito with authorization grant
  4. Cognito federates - Validates with Azure AD and creates session
  5. Tokens returned - Cognito redirects to app with ID token and access token in URL hash
  6. User Info displayed - Your information from Azure AD is extracted from the ID token

This demonstrates the OAuth 2.0 implicit flow with OIDC, where authentication happens entirely at Azure AD, and Cognito acts as the federation layer. Tokens are returned directly to the browser (no backend required).

Built with AWS Cognito, Azure AD, and Terraform
